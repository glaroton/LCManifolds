LCManifolds

Manifolds modeled on locally convex spaces, formalized in Lean 4 and Mathlib.

API documentation Source on GitHub

Status: early stage. At present the library contains the basic definition only. It is the geometric companion of LCAnalysis, which provides the calculus.

Contents

  • LCManifolds/Basic.lean:
  • mbGroupoid E, the structure groupoid of Michal–Bastiani smooth diffeomorphisms between open subsets of a locally convex space E;
  • MBManifold, smooth manifolds modeled on E [Nee06, Def. I.3.1; GN26, Ch. 3].

There is no sorry.

Design

Mathlib's ChartedSpace and StructureGroupoid accept an arbitrary topological model space, so Mathlib's chart machinery is reused directly. A manifold modeled on E is a ChartedSpace E M with HasGroupoid M (mbGroupoid E). Only the notion of smoothness changes: Mathlib's contDiffGroupoid needs a normed model with corners, and this library replaces it with the Michal–Bastiani calculus of LCAnalysis.

Planned

  2. Tangent spaces, the tangent bundle and the tangent map.
  3. Lie groups modeled on locally convex spaces and their Lie algebras [Nee06, GN26].
